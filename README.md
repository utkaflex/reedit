Редизайн 04.11.2026: [реализованное, проверки и ограничения](docs/redesign-2026-11-04.md), [desktop/mobile снимки](docs/screenshots/redesign-2026-11-04/README.md).

Исправления после первой проверки на iPhone: [импорт, читалка и мобильные экраны](docs/iphone-hotfix.md). Обновление установленной PWA: Настройки → Работа офлайн → Проверить обновления → Обновить приложение, после выхода из чтения.

Локальная PWA-читалка для iPhone: библиотека, EPUB/FB2, обычное чтение, RSVP/Guided, аннотации, статистика и дневник. Все пользовательские данные локальны в IndexedDB (аддитивная схема v9). Офлайн-оболочка и ZIP-копии описаны в [pwa.md](docs/pwa.md) и [backup.md](docs/backup.md). Внешние каталоги предоставляют только метаданные через ограниченный proxy.

Node 24, pnpm 11.25.0: `pnpm install --frozen-lockfile`, затем `pnpm dev`.

Railway: [пошаговая инструкция](docs/deployment.md). Один Docker-сервис, сервер использует `PORT`, проверка готовности — `/healthz`. БД и Volume не нужны. Публичный адрес владельца: https://reedit-production.up.railway.app/.

Локальная production-проверка: `pnpm build`, затем `pnpm start`, адрес `http://localhost:4174`. Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm test:e2e --project chromium --project chromium-mobile --workers 1`, `pnpm test:pwa`, `pnpm format:check`. Отчёт и ограничения: [финальный аудит](docs/release-audit.md).

Перед переносом на другой домен сохраните полную ZIP-копию вне приложения. Хранилище привязано к адресу и браузеру; подключение репозитория к Railway не переносит вашу библиотеку.

Документация: [архитектура](docs/architecture.md), [модель данных](docs/data-model.md), [решения](docs/decisions.md), [разработка](docs/development.md), [этапы](docs/roadmap.md).

[Визуальная система](docs/design-system.md) описывает токены, темы и компоненты. Основные ссылки: `#/library`, `#/quotes`, `#/statistics`, `#/settings`. Читалка открывается из карточки книги для выбранного EPUB и прочтения.

[Импорт EPUB](docs/epub-import.md): поддержанные варианты, лимиты, безопасность и гарантии сохранности. `pnpm fixtures:epub` воспроизводит синтетические CC0-фикстуры; они не загружаются в библиотеку при запуске.

[Импорт FB2](docs/fb2-import.md): безопасный XML, исходный файл и локальное EPUB-представление для общей читалки, стихи/примечания/изображения, ограничения и проверки согласованности текста.

[Читалка](docs/reader.md): управление, позиции, адаптер и ручная проверка iPhone. Service Worker включён в production: `pnpm build`, затем `pnpm preview`. Автотесты: `pnpm test:pwa`.

[Единая позиция](docs/positions.md): версионируемый читаемый текст, ReadingCursor, CFI ↔ DOM Range, текстовый прогресс и сохранение общего ориентира после изменения оформления и перезапуска. Реализованные режимы используют общий курсор.

[Аннотации](docs/annotations.md): нативное выделение, цвета и комментарии, именованные закладки, общий список цитат, поиск/фильтры и Markdown/TXT. Заметки доступны без EPUB; точный повторный импорт восстанавливает привязку.

[Скорочтение](docs/speed-reading.md): RSVP и Guided Reading, 100–900 WPM, настраиваемые интеллектуальные паузы, общий курсор и возврат к текущему слову, автоматическая пауза в фоне. Настройки и позиция хранятся локально.

[Поиск в каталогах](docs/catalog-search.md): Google Books/Open Library, конкретные издания, редактируемые метаданные и обложки, сопоставление без потери истории. В разработке запустите также `pnpm start` для catalog proxy; Google включается серверным GOOGLE_BOOKS_API_KEY. Библиотека и EPUB по-прежнему локальны.
