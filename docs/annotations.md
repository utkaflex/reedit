# Аннотации · этап 07

В читалке используйте обычное системное выделение текста (long press на iPhone). Reedit не отменяет contextmenu, не заменяет selection handles и не оборачивает текст дополнительными span. Нижняя панель предлагает выделение песочным цветом, заметку с выбором цвета, копирование и системное «Поделиться». Копирование/Share показываются только при наличии браузерного API; HTTPS/localhost необходим для Clipboard. Отказ разрешения показан как ошибка, отмена Share не является ошибкой. Системное меню Safari может временно закрывать кнопки приложения: завершите изменение границ и используйте нижнюю панель.

Комментарий и цвет можно изменить в списке. Кнопка закладки сохраняет именованный якорь **начала видимого фрагмента**, а не случайное слово. Списки доступны из читалки, карточки книги и общего раздела `#/quotes`. Есть поиск по цитате/комментарию/названию книги, фильтры книги, цвета и дат создания (локальные календарные дни, обе границы включены), отдельный список закладок. Экспорт Markdown/TXT включает текущую отфильтрованную выборку цитат, комментарии, название книги и UTC дату. Markdown экранирует пользовательские символы. Экспорт — локальная загрузка; автоматической отправки нет.

## Привязка и сохранность

Новая Annotation содержит UUID, bookId, readingId, nullable bookFileId, quote (непустой нормализованный текст индекса), note, color, CFI Range и TextAnchor. Время создания и изменения — Unix UTC ms. TextAnchor хранит contentId=`originalSHA256:renderedSHA256`, start/end ReadingCursor (UTF-16 offsets в одном spine-ресурсе, диапазон `[start,end)`), до 48 символов контекста перед/после. У EPUB оба хеша одинаковы; у FB2 второй относится к сохранённому EPUB-представлению. Версия алгоритма входит в оба курсора. Привязка и quote неизменяемы; редактируются комментарий, цвет и подпись закладки. Bookmark использует ту же привязку с start=end, без цитаты.

PositionResolver создаёт CFI Range из оригинального DOM, согласованного с индексом. Нормализация цитаты может объединить переносы/пробелы, убрать мягкий дефис и привести комбинируемые символы к NFC: это те же правила, что у единой позиции. Выделение ограничено одним загруженным XHTML (iframe); диапазон между разными spine-документами не создаётся. Элементы, исключённые из читаемого индекса, не дают пустые цитаты.

Переход и отрисовка проверяют оба хеша, версию индекса, offsets, цитату и окружающий контекст. Неправильный/устаревший сохранённый CFI не передаётся движку: из проверенных offsets заново строится канонический CFI. Несовпадение текста/контекста/версии даёт понятную ошибку перехода, цитата остаётся доступна. Для старых записей без проверенной привязки переход отключён; алгоритма угадывания по названию/ISBN нет.

Выделения рисует штатный SVG annotations слой epub.js вне текстового DOM. Они восстанавливаются при релокации, смене шрифта, темы, режима и повторном открытии. Палитра фиксирована, HTML/CSS из комментариев не исполняется. Слушатель selectionchange только снимает копию Range/offsets, без preventDefault или искусственного изменения системного выделения. Для кнопок нижнего меню предотвращается перевод pointer-фокуса, чтобы Safari не сбросил Range перед действием; перед открытием редактора снимок уже сохранён в состоянии UI. Диалог учитывает visualViewport при клавиатуре, сохраняет focus trap/возврат фокуса и прокрутку.

Запись проходит через LocalStore/репозитории. Транзакционная проверка readingId+contentId+версия+spine+start/end предотвращает повторные цитаты даже при двух одновременных сохранениях. Повторное сохранение возвращает существующую запись; попытка молча заменить другой комментарий отклоняется с предложением редактировать запись. UI дополнительно блокирует повторные запросы. Пустая цитата не сохраняется; пустой комментарий допустим для обычного выделения. Оптимистическая проверка updatedAt защищает редактирование/удаление от устаревшей формы. Ошибка квоты не оставляет частичной записи.

Удаление BookFile сохраняет UUID, quote, note, цвет, CFI, TextAnchor и Reading, выставляет bookFileId=null. Список и редактирование доступны, переход отключён. Импорт в **ту же Book** атомарно восстанавливает bookFileId только при совпадении original+rendered SHA; другое издание не привязывается. Файл не ищется по имени/ISBN/обложке. После повторного импорта комментарий можно редактировать до повторного построения производного индекса; новый диапазон без проверенного индекса создать нельзя. Удаление всей Book остаётся отдельной подтверждаемой операцией с явным предупреждением о заметках.

## Миграция v6 и проверки

V6 добавляет индексы bookId/createdAt для annotations/bookmarks. Upgrade восстанавливает bookId через Reading и песочный цвет у старых аннотаций; не читает EPUB Blob, не меняет CFI/quote/note/UUID/временные метки и не придумывает offsets. Даже запись с отсутствующим родителем сохраняется, без автоматического перехода.

Автотесты: сохранение/редактирование, конкурирующий дубль, квота и откат, миграция v5, сохранность после удаления файла и reopen, другое издание и повторное прикрепление идентичного оригинала, 198 комбинаций CFI Range ↔ DOM ↔ offsets. Браузерные сценарии проверяют изменение Selection, комментарий/цвет, SVG после смены темы, bookmark, фильтры, локальный экспорт, перезапуск, переход с испорченным CFI, удаление/повторный импорт файла. Синтетические selection Range в автоматизации не заменяют проверку iOS.

Обязательная ручная проверка на физическом iPhone Safari (узкая модель и портрет/ландшафт):

1. Long press, системное меню «Копировать/Поделиться», изменение обеих границ и выделение через курсив/переносы. Не должно перелистывать или скрывать панели жестом.
2. Нижнее меню, заметка, появление/закрытие клавиатуры, прокрутка большого комментария, возврат фокуса; панель не закрывает текст и safe-area.
3. Выделение и переход после изменения шрифта/полей/темы, смены ориентации, прокрутки и перезапуска Safari.
4. Реальные Clipboard/Web Share, отказ разрешения и отмена системного share sheet, Markdown/TXT через загрузки Safari.
5. Удаление EPUB, чтение/редактирование оставшейся заметки, повторный импорт тех же байтов и другого издания; ни одна цитата не исчезает и не переезжает в неверный текст.

В текущем окружении WebKit не сохраняет Blob в IndexedDB даже на пустой странице (ошибка `Error preparing Blob/File data to be stored in object store`), поэтому импортные E2E в нём не подтверждают работу Safari. Физический iPhone здесь недоступен; native long press, handles, системное меню и клавиатура остаются ручной проверкой. Guided Reading/RSVP не реализованы.
